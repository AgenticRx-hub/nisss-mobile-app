Try this

  2. On Contributions, filter the history, then pay two outstanding self-employed months and open the receipt.
  3. On Pension estimator, move the sliders and watch the estimate and the qualifying-weeks check update.
  4. On Claims (Phase 2), start a sickness benefit claim, attach a document and follow its status.

Software and hardware architecture, security · RFB §1.3, §1.4.3, §3.1

Secure multi-tier architecture

Native-quality iOS and Android apps talk only to an API Gateway. Behind it sit stateless application services, an integration layer to NISSS's own REST APIs, and an encrypted, replicated database. NISSS's systems of record are never exposed to the internet.

Security controls

IdentityOAuth 2.0 / OpenID Connect via NISSS's SaaS IAM; multi-factor sign-in; biometric unlock bound to device keys
Data in transitTLS 1.2+ everywhere, certificate pinning in the app
Data at restAES-256 database and backup encryption; keys in a managed KMS; no personal data cached unencrypted on the device
AccessRole-based access control for staff; least privilege for services
DetectionWAF, intrusion detection, centralised audit logging into a SIEM
AssuranceOWASP MASVS / Mobile Top 10 testing, independent penetration test, no critical or high findings at go-live

Standards and law
